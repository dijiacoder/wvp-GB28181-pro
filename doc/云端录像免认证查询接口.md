# 云端录像免认证查询接口

根据流 ID 和时间范围查询云端录像，无需登录认证，不分页。

## 接口信息

- 请求方式：`GET`
- 接口路径：`/api/cloud/record/open/list`
- 认证方式：无需 Token 或 Authorization 请求头
- 响应格式：`application/json`

## 请求参数

通过 URL 查询参数传入以下三个必填参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| stream | string | 是 | 流 ID，精确匹配，不能为空 |
| startTime | string | 是 | 开始时间，格式为 `yyyy-MM-dd HH:mm:ss` |
| endTime | string | 是 | 结束时间，格式为 `yyyy-MM-dd HH:mm:ss`，不能早于开始时间 |

时间按照服务端配置的时区解析。URL 中的空格需编码为 `%20` 或 `+`。

查询规则：录像结束时间大于等于 startTime，且录像开始时间小于等于 endTime，即返回与查询时间范围重叠的全部录像。按录像开始时间降序排列，不限制应用名或媒体节点。

## 请求示例

```http
GET http://172.16.5.102:18080/api/cloud/record/open/list?stream=1581F5BMD23BA0024K00&startTime=2026-11-05%2015:09:10&endTime=2026-11-05%2015:15:21
```

```bash
curl --get 'http://172.16.5.102:18080/api/cloud/record/open/list' \
  --data-urlencode 'stream=1581F5BMD23BA0024K00' \
  --data-urlencode 'startTime=2026-11-05 15:09:10' \
  --data-urlencode 'endTime=2026-11-05 15:15:21'
```

## 成功响应

以下数据仅作格式示例，实际结果以服务器查询为准。

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "total": 1,
    "list": [
      {
        "id": 3161,
        "app": "drone",
        "stream": "1581F5BMD23BA0024K00",
        "startTime": 1793862574000,
        "endTime": 1793862921000,
        "fileName": "2026-11-05-15-09-34-0.mp4",
        "playUrl": "http://172.16.5.102:80/index/api/downloadFile?file_path=/opt/media/bin/www/record/drone/1581F5BMD23BA0024K00/2026-11-05/2026-11-05-15-09-34-0.mp4",
        "fileSize": 98430764
      }
    ]
  }
}
```

### 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | integer | 业务状态码，`0` 表示成功 |
| msg | string | 结果说明 |
| data.total | integer | 返回录像总条数，与 list 长度一致 |
| data.list | array | 全部匹配的录像，无分页 |
| data.list[].id | integer | 录像 ID |
| data.list[].app | string | 流应用名 |
| data.list[].stream | string | 流 ID |
| data.list[].startTime | integer | 录像开始时间，Unix 时间戳，单位毫秒 |
| data.list[].endTime | integer | 录像结束时间，Unix 时间戳，单位毫秒 |
| data.list[].fileName | string | 录像文件名 |
| data.list[].playUrl | string | 录像访问地址，使用所属媒体节点的 streamIp 和 HTTP 端口生成 |
| data.list[].fileSize | integer | 录像文件大小，单位字节 |

没有匹配录像时仍返回成功：

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "total": 0,
    "list": []
  }
}
```

## 错误说明

以下情况会返回错误，具体响应遵循服务端统一异常处理：

- 缺少必填参数。
- stream 为空或仅包含空格。
- 时间格式不符合 `yyyy-MM-dd HH:mm:ss`。
- 开始时间晚于结束时间。
- 查询结果中的录像所属媒体节点不存在。

接口免认证仅适用于此查询地址。playUrl 的访问还取决于媒体节点网络可达性及其访问配置。
